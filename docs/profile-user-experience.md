# Experiencia de Mi perfil

La navegación principal expone `Mi perfil`. La pantalla agrupa información personal, progreso corporal y `Mi membresía y accesos`, con navegación horizontal desplazable en móvil.

Muestra plan, estado efectivo, fechas, días restantes, beneficios, derechos e historial. Las acciones cambian por estado: extensión para activa, advertencia próxima a vencer, tienda/WhatsApp para vencida y pago pendiente sin acceso anticipado.

Las tarjetas tienen dimensiones estables, carga diferida, alt text y fallback; una portada caída no oculta precio, beneficios ni CTA.
